# 自製看圖軟體 第一版規格

Nov 1, 2026 · @偉欽

## 目標與原則

第一版是一個只跑在 Windows 上、單一執行檔、開資料夾一秒內出縮圖的看圖程式，操作方式比照 ACDSee 3.2。

- **小**：安裝檔 2 MB 以內，不需另裝執行環境（不用 .NET、不用 VC++ 可轉散發套件，靜態連結）。
- **快**：啟動 0.5 秒內，縮圖在背景執行緒產生，捲動時不卡畫面。
- **簡單**：只做看圖與基本整理，不做修圖、不做資料庫式圖庫。
- **技術**：C++17、Win32 API、WIC 解碼、Direct2D 繪圖，Windows 10 / 11 64 位元。

## ACDSee 3.2 操作模式

程式只有兩個模式，用 Enter 或雙擊在兩者間切換，這是 ACDSee 3.2 最核心的手感。

**瀏覽模式**（開程式時的畫面）

- 左上：資料夾樹，顯示所有磁碟與資料夾。
- 左下：預覽窗，顯示目前選取的圖。
- 右側：檔案清單，可切換縮圖、大圖示、清單、詳細資料四種檢視。
- 上方：網址列（上層、重新整理、可直接輸入路徑），下面是指令列（看圖、旋轉、改名、刪除、資訊、排序、檢視、「⋯」完整選單）。按 Alt 或 F10 開啟完整選單，Alt+字母（如 Alt+F）照舊可用。
- 下方：狀態列，顯示檔案數、選取數、圖片尺寸與檔案大小。
- 外觀採 Windows 10/11 風格：跟隨系統深色／淺色模式，圖示用系統內建的 Segoe Fluent Icons（Windows 10 為 Segoe MDL2 Assets）。

**檢視模式**（看單張圖）

- 圖片佔滿視窗，預設「縮小至視窗大小、不放大小圖」。
- 指令列換成看圖用的按鈕：返回瀏覽、上一張／下一張、縮放、旋轉、改名、刪除、資訊、自動播放、全螢幕。
- 可切全螢幕，全螢幕時隱藏指令列與狀態列。
- 換圖依瀏覽模式的排序順序，並預先載入下一張讓換圖沒有等待。
- 回到瀏覽模式時，清單選取停在剛才看的那張。

## 支援格式與效能目標

格式全靠 Windows 內建的 WIC 解碼，不內嵌第三方函式庫，這是安裝檔能維持 2 MB 以內的關鍵。

- **一定支援**：JPEG、PNG、GIF（第一影格）、BMP、TIFF、ICO。
- **有裝系統擴充就支援**：WebP、HEIC、AVIF、各家相機 RAW、JPEG XL（Windows 10/11 從 Microsoft Store 裝擴充即可）。
  資料夾裡有這些格式但還沒裝擴充時，狀態列會顯示「有 N 個 … 檔案需要安裝 Windows 擴充」，按一下直接開 Store 安裝頁；「說明 → 取得更多圖片格式」可檢查整台電腦缺哪些。HEIC 另需 HEVC 視訊延伸模組，打不開時檢視畫面會提示。
- **文字檔**：txt、md、log、csv、json、xml、yaml、ini 與常見程式碼。瀏覽模式的預覽窗格顯示開頭幾行；按 Enter 進入檢視模式，用等寬字型唯讀顯示（自動換行，可選取複製，+/- 調整字級），編碼自動判斷 UTF-8／UTF-16／系統 ANSI（繁中 Windows 為 Big5），超過 8 MB 只顯示開頭。PageUp/PageDown/空白鍵在文字頁用來捲動，換檔用滑鼠或命令列按鈕。

| 指標 | 目標 |
| --- | --- |
| 安裝檔大小 | ≤ 2 MB |
| 程式啟動到可操作 | ≤ 0.5 秒 |
| 開 1,000 張的資料夾，第一屏縮圖出現 | ≤ 1 秒 |
| 檢視模式換圖（12 MP JPEG，已預載） | ≤ 50 毫秒 |
| 開 10,000 張的資料夾時記憶體 | ≤ 300 MB |

## 第一版不做的範圍

- 修圖：裁切、調色、濾鏡、加文字。
- 格式轉換與批次縮圖。
- 標籤、評分、圖庫資料庫。
- 列印、上傳、分享。
- GIF 動畫播放、影片。
- 多語系：第一版只做繁體中文介面，但字串集中管理以便日後加英文。
- Mac、Linux 版。

## 已定案的預設

- 快捷鍵：依上表。
- 檔案關聯：安裝時提供勾選項「設為預設看圖程式」，預設不勾。
- 綠色版：同一個執行檔，旁邊有 portable.ini 就把設定與快取存在程式資料夾。
- 程式名稱：暫定 LiteView（執行檔 LiteView.exe），隨時可改。
